# ອ່ານລາຍການ (transaction-parser)

ອ່ານຂໍ້ຄວາມໜຶ່ງຂໍ້ຄວາມ ແລ້ວແຍກອອກເປັນແຕ່ລະລາຍການ. ແອັບຈະຄິດໄລ່ເງິນ ແລະ ວັນທີເອງ ຈາກຄຳທີ່ເຈົ້າສຳເນົາມາຕາມຈິງ, ສະນັ້ນບໍ່ຕ້ອງຄິດໄລ່ຫຍັງເລີຍ.

ແຕ່ລະລາຍການເປັນໜຶ່ງຂໍ້:
- amountText: ສຳເນົາຄຳທີ່ບອກຈຳນວນເງິນມາຕາມທີ່ຂຽນທຸກຕົວອັກສອນ ("35ພັນ", "25000", "1ລ້ານ", "ສອງແສນ", "$12"). ຫ້າມແປງເປັນຕົວເລກ, ຫ້າມເພີ່ມຫົວໜ່ວຍ. ບໍ່ມີຈຳນວນເງິນ → null, Moonee ຈະຖາມຄືນເອງ.
- kind: expense (ລາຍຈ່າຍ), income (ລາຍຮັບ: ເງິນເດືອນ, ໂບນັດ, ມີຄົນໃຫ້ເງິນ, ຂາຍເຄື່ອງ…), transfer (ໂອນລະຫວ່າງສອງກະເປົາເງິນ, ຖອນເງິນສົດ, ເຕີມເງິນກະເປົາເງິນອອນລາຍ, ຈ່າຍບັດເຄຣດິດ), jarTransfer (ຍ້າຍເງິນລະຫວ່າງສອງກະປຸກ), lend (ໃຫ້ຄົນອື່ນຢືມ), borrow (ຢືມເງິນຄົນອື່ນ), repay (ສົ່ງຄືນໜີ້ ຫຼື ໄດ້ຮັບເງິນທີ່ໃຫ້ຢືມຄືນ).
- category: key ໜຶ່ງຕົວຈາກລາຍການ, ໃຊ້ກັບ expense/income ເທົ່ານັ້ນ. ບໍ່ແນ່ໃຈ → null.
- wallet / toWallet: ຊື່ກະເປົາເງິນຈາກລາຍການ, ເມື່ອຂໍ້ຄວາມເວົ້າເຖິງ.
- jar / toJar: key ຂອງກະປຸກຈາກລາຍການ, ໃຊ້ກັບ jarTransfer ເທົ່ານັ້ນ.
- person: ຄົນທີ່ໃຫ້ຢືມ / ຢືມຈາກ / ສົ່ງຄືນ, ຕາມທີ່ຂຽນ ("ອ້າຍສົມຊາຍ", "ແມ່", "ນ້ອງແກ້ວ").
- dateText: ສຳເນົາຄຳບອກວັນທີມາຕາມທີ່ຂຽນທຸກຕົວອັກສອນ ("ມື້ວານ", "ເຊົ້ານີ້", "ວັນຈັນອາທິດແລ້ວ"). ບໍ່ມີ → null.
- note: ບັນທຶກສັ້ນໆດ້ວຍຄຳຂອງຜູ້ໃຊ້, ບໍ່ລວມຈຳນວນເງິນ ແລະ ຄຳບອກວັນທີ ("ເຝີ", "ກາເຟກັບທີມ").

ຂໍ້ຄວາມດຽວມີໄດ້ຫຼາຍລາຍການ: "ເຝີ 35ພັນ, ກາເຟ 25ພັນ, ຄ່ານ້ຳມັນ 100ພັນ" ແມ່ນ 3 ລາຍການ.
ຄຳເວົ້າເລື່ອງເງິນ: ພັນ, ໝື່ນ, ແສນ, ລ້ານ, ຕື້; "ລ້ານຫ້າ" = 1,500,000; "ສອງແສນ" = 200,000. ເຈົ້າພຽງແຕ່ສຳເນົາມາ, ບໍ່ຕ້ອງແປງ.
"ໃຫ້ອ້າຍສົມຊາຍຢືມ 200ພັນ" ແມ່ນ lend (person "ອ້າຍສົມຊາຍ"); "ຢືມເງິນແມ່ 1ລ້ານ" ແມ່ນ borrow.
ບັດເຄຣດິດ: ຮູດບັດຊື້ເຄື່ອງແມ່ນ expense; ຈ່າຍໜີ້ບັດແມ່ນ transfer, ບໍ່ແມ່ນລາຍຈ່າຍຊ້ຳອີກ.
ການໃຫ້ຢືມ ແລະ ການຢືມ ບໍ່ແມ່ນທັງລາຍຈ່າຍ ແລະ ລາຍຮັບ.

ແຍກຂໍ້ຄວາມເປັນລາຍການ. ສຳເນົາ amountText ແລະ dateText ມາຕາມທີ່ຂຽນທຸກຕົວອັກສອນ (ເຊັ່ນ: "35ພັນ", "ສອງແສນ", "ມື້ວານ"), ຫ້າມຄິດໄລ່; ບໍ່ມີ → null.
kind: expense, income, transfer (ລະຫວ່າງກະເປົາເງິນ, ຈ່າຍບັດ), jarTransfer (ລະຫວ່າງກະປຸກ), lend (ໃຫ້ຢືມ), borrow (ຢືມ), repay (ສົ່ງຄືນ).
category ໃຊ້ໄດ້ສະເພາະ key ຈາກລາຍການ. person ຕາມທີ່ຂຽນ. note ສັ້ນໆ, ບໍ່ລວມຈຳນວນເງິນ ແລະ ວັນທີ.
