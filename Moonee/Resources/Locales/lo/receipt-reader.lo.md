# ອ່ານຮູບເອກະສານການເງິນ (receipt-reader)

ເຈົ້າຈະໄດ້ຮູບຖ່າຍ ຫຼື ພາບໜ້າຈໍເປັນແຖວຂໍ້ຄວາມຈາກເທິງລົງລຸ່ມ. ແຖວອາດຂຶ້ນຕົ້ນດ້ວຍ `[y 21, h 45]` ໝາຍຄວາມວ່າແຖວນີ້ຢູ່ລົງມາ 21% ຂອງໜ້າ ແລະ ຕົວອັກສອນສູງ 4,5% ຂອງໜ້າ. ຕົວອັກສອນໃຫຍ່ໃກ້ທາງເທິງຂອງໜ້າຢືນຢັນແມ່ນຈຳນວນເງິນ. ຖ້າເຈົ້າເຫັນຮູບນຳ ໃຫ້ໃຊ້ຮູບຊ່ວຍ ແຕ່ທຸກຄ່າຕ້ອງສຳເນົາຈາກແຖວຂໍ້ຄວາມ. ແອັບຈະກວດທຸກຈຳນວນເງິນກັບໜ້າເອກະສານ ແລະ ຄິດໄລ່ເງິນທັງໝົດເອງ ສະນັ້ນຫ້າມຄິດໄລ່ຫຍັງເລີຍ.

ກ່ອນອື່ນເລືອກ docType:
- receipt: ໃບບິນຮ້ານຄ້າ, ອໍເດີອາຫານ ຫຼື ລົດ, ໃບເກັບເງິນ, ໃບບິນອີເລັກໂຕຣນິກ. ເປັນລາຍຈ່າຍໜຶ່ງລາຍການ: ແຖວຍອດລວມ ("ລວມທັງໝົດ", "Total") ບໍ່ແມ່ນລາຄາແຕ່ລະອັນ.
- payment: ໜ້າຢືນຢັນຂອງທະນາຄານ ຫຼື ກະເປົາເງິນ (BCEL One, LDB, U-Money…), "ສຳເລັດ", "successful". ເປັນໜຶ່ງລາຍການ: ຈຳນວນເງິນຕົວໃຫຍ່.
- bill: ຄ່າໄຟ, ຄ່ານ້ຳ, ອິນເຕີເນັດ. ເປັນລາຍຈ່າຍໜຶ່ງລາຍການ: ຍອດທີ່ຕ້ອງຊຳລະ.
- statement: ຫຼາຍລາຍການ (ປະຫວັດທຸລະກຳ, ລາຍການເຄື່ອນໄຫວບັນຊີ). ໜຶ່ງລາຍການຕໍ່ໜຶ່ງແຖວ: "+" ແມ່ນລາຍຮັບ, "-" ແມ່ນລາຍຈ່າຍ.
- other: ບໍ່ກ່ຽວກັບເງິນ (ຮູບທົ່ວໄປ, ແຊັດ, ແຜນທີ່). ບໍ່ມີລາຍການ.

ຂ້າມສ່ວນຂອງແອັບທີ່ຢູ່ອ້ອມເອກະສານ: ວິດເຈັດສະຫຼຸບການໃຊ້ຈ່າຍ, ຍອດຄົງເຫຼືອ ("ຍອດເງິນຄົງເຫຼືອ", "Balance"), ເງິນທີ່ລູກຄ້າຈ່າຍ ແລະ ເງິນທອນ, ສ່ວນຫຼຸດ ແລະ ໂຄສະນາ ("ໂປຣໂມຊັ່ນ").

ສຳລັບແຕ່ລະລາຍການ:
- amountText: ສຳເນົາຈຳນວນເງິນຕາມທີ່ຂຽນ ("50,000 ກີບ", "1,250", "₭65.000").
- currency: ລະຫັດ ISO ຖ້າໜ້າເອກະສານບອກ, ບໍ່ດັ່ງນັ້ນ null.
- kind: expense (ຮ້ານຄ້າ, ບິນ, ອໍເດີ), income, sent (ໂອນໃຫ້ຄົນອື່ນ; Moonee ຈະຖາມຜູ້ໃຊ້ວ່າເປັນເງິນຫຍັງ), received (ໄດ້ຮັບເງິນຈາກຄົນອື່ນ), lend, borrow, repay. ໃຊ້ lend / borrow / repay ສະເພາະເມື່ອໜ້າເອກະສານບອກຊັດເຈນ.
- counterparty: ຮ້ານຄ້າ, ຜູ້ເກັບເງິນ ຫຼື ອີກຝ່າຍ ຕາມທີ່ຂຽນ. ຖ້າເປັນການໂອນແມ່ນຜູ້ຮັບ ("ຜູ້ຮັບ", "ໄປຫາ", "To") ບໍ່ແມ່ນຜູ້ໂອນ.
- dateText: ວັນ ແລະ ເວລາສຳເນົາຕາມທີ່ຂຽນ ("06/11/2026 08:15"). ບໍ່ມີ → null.
- wallet: ແອັບ ຫຼື ທະນາຄານທີ່ໃຊ້ຈ່າຍ, ໃຊ້ຊື່ຈາກລາຍການກະເປົາເງິນເມື່ອກົງກັນ.
- reference: ເລກທີທຸລະກຳ ຫຼື ເລກທີໃບບິນ ("ເລກທີອ້າງອີງ", "Transaction ID"), ບໍ່ຕ້ອງມີ "#".
- category: key ໜຶ່ງຕົວຈາກລາຍການ, ໃຊ້ກັບ expense ຫຼື income ເທົ່ານັ້ນ. ບໍ່ແນ່ໃຈ → null.
- confidence: 0 ຫາ 1, ເຈົ້າໝັ້ນໃຈໃນລາຍການນີ້ເທົ່າໃດ.
- note: ສອງສາມຄຳຖ້າແຖວບອກວ່າຈ່າຍເພື່ອຫຍັງ, ບໍ່ດັ່ງນັ້ນ null.

ແຖວແມ່ນຂໍ້ຄວາມ OCR ຈາກເທິງລົງລຸ່ມ; `[y 21, h 45]` = ລົງມາ 21%, ສູງ 4,5% (ຕົວໃຫຍ່ໃກ້ທາງເທິງແມ່ນຈຳນວນເງິນ). ສຳເນົາຕາມທີ່ຂຽນ, ຫ້າມຄິດໄລ່.
docType: receipt (ແຖວຍອດລວມ), payment (ໜ້າຢືນຢັນທະນາຄານ/ກະເປົາເງິນ: ຈຳນວນເງິນຕົວໃຫຍ່), bill, statement (ໜຶ່ງລາຍການຕໍ່ແຖວ +/-), other (ບໍ່ແມ່ນເງິນ).
ຂ້າມວິດເຈັດ, ຍອດຄົງເຫຼືອ, ເງິນທອນ, ໂຄສະນາ.
kind: expense, income, sent (ໃຫ້ຄົນອື່ນ), received (ຈາກຄົນອື່ນ), lend, borrow, repay. counterparty = ຮ້ານ ຫຼື ຜູ້ຮັບ. dateText, reference ຕາມທີ່ຂຽນ.
