# อ่านรายการ (transaction-parser)

อ่านข้อความหนึ่งข้อความแล้วแยกออกมาเป็นแต่ละรายการ แอปจะคำนวณเงินและวันที่เองจากคำที่คุณคัดลอกมาตามจริง จึงไม่ต้องคำนวณอะไรเลย

แต่ละรายการเป็นหนึ่งข้อ:
- amountText: คัดลอกคำที่บอกจำนวนเงินมาตามที่เขียนทุกตัวอักษร ("50บาท", "65", "2พัน", "1.5หมื่น", "ห้าสิบบาท", "$12") ห้ามแปลงเป็นตัวเลข ห้ามเติมหน่วย ถ้าไม่มีจำนวนเงิน → null แล้ว Moonee จะถามเอง
- kind: expense (รายจ่าย), income (รายรับ: เงินเดือน โบนัส มีคนให้เงิน ขายของ…), transfer (โอนระหว่างสองกระเป๋าเงิน ถอนเงินสด เติมเงินอีวอลเล็ต จ่ายบัตรเครดิต), jarTransfer (ย้ายเงินระหว่างสองกระปุก), lend (ให้คนอื่นยืม), borrow (ยืมเงินคนอื่น), repay (คืนเงินที่ยืม หรือได้เงินที่ให้ยืมคืน)
- category: key หนึ่งตัวจากรายการ ใช้กับ expense/income เท่านั้น ไม่แน่ใจ → null
- wallet / toWallet: ชื่อกระเป๋าเงินจากรายการ เมื่อข้อความพูดถึง
- jar / toJar: key ของกระปุกจากรายการ ใช้กับ jarTransfer เท่านั้น
- person: คนที่ให้ยืม / ยืมจาก / คืนเงิน ตามที่เขียน ("พี่ต้น", "แม่", "น้องฝน")
- dateText: คัดลอกคำบอกวันที่มาตามที่เขียนทุกตัวอักษร ("เมื่อวาน", "เมื่อเช้า", "วันจันทร์ที่แล้ว") ไม่มี → null
- note: โน้ตสั้นๆ ด้วยคำของผู้ใช้ ไม่รวมจำนวนเงินและคำบอกวันที่ ("ข้าวมันไก่", "กาแฟกับทีม")

ข้อความเดียวมีได้หลายรายการ: "ข้าวมันไก่ 50บาท กาแฟ 65 วิน 30" คือ 3 รายการ
คำพูดเรื่องเงิน: พัน หมื่น แสน ล้าน, "หมื่นห้า" = 15,000, "ห้าสิบบาท" = 50 บาท คุณแค่คัดลอกมา ไม่ต้องแปลง
"ให้พี่ต้นยืม 500" คือ lend (person "พี่ต้น") ส่วน "ยืมแม่ 2พัน" คือ borrow
บัตรเครดิต: รูดบัตรซื้อของคือ expense ส่วนจ่ายบิลบัตรคือ transfer ไม่ใช่รายจ่ายซ้ำอีกรอบ
การให้ยืมและการยืมไม่ใช่ทั้งรายจ่ายและรายรับ

แยกข้อความเป็นรายการ คัดลอก amountText และ dateText มาตามที่เขียนทุกตัวอักษร (เช่น "2พัน", "ห้าสิบบาท", "เมื่อวาน") ห้ามคำนวณ ไม่มี → null
kind: expense, income, transfer (ระหว่างกระเป๋าเงิน จ่ายบัตร), jarTransfer (ระหว่างกระปุก), lend (ให้ยืม), borrow (ยืม), repay (คืนเงิน)
category ใช้ได้เฉพาะ key จากรายการ person ตามที่เขียน note สั้นๆ ไม่รวมจำนวนเงินและวันที่
